# Keyboard Shortcuts Reference

> All shortcuts use `Ctrl` on Windows/Linux and `⌘` on macOS.

## Global

| Shortcut | Action |
|----------|--------|
| `Ctrl+K` | Open Command Palette |
| `Ctrl+N` | New Project |
| `Ctrl+O` | Open Project |
| `Ctrl+S` | Save Project |
| `Ctrl+Shift+S` | Save Project As |
| `Ctrl+Z` | Undo |
| `Ctrl+Shift+Z` | Redo |
| `F` | Toggle Fullscreen Canvas |
| `Shift+F` | Toggle Distraction-Free Mode |
| `Delete` | Delete Selected Asset |

## Workspace Switching

| Shortcut | Action |
|----------|--------|
| `Ctrl+1` | Switch to Extract |
| `Ctrl+2` | Switch to Foundry |
| `Ctrl+3` | Switch to Design |
| `Ctrl+4` | Switch to Animate |
| `Ctrl+5` | Switch to Export |

## Extract Workspace

| Shortcut | Action |
|----------|--------|
| `V` | Select Tool |
| `C` | Circle Extract Tool |
| `R` | Rect Extract Tool |
| `S` | Smart Select Tool (SAM) |
| `W` | Magic Wand Tool |
| `H` | Hand / Pan Tool |
| `Z` | Zoom Tool |
| `Ctrl+0` | Zoom to Fit |
| `Ctrl+G` | Toggle Pixel Grid |
| `Space` (hold) | Temporary Pan |

## Design Workspace

| Shortcut | Action |
|----------|--------|
| `V` | Select |
| `M` | Move |
| `T` | Rotate |
| `Ctrl+G` | Group |
| `'` | Toggle Snap |

## Animate Workspace

| Shortcut | Action |
|----------|--------|
| `Space` | Preview |
| `L` | Loop |
| `G` | Generate Frames |

## Export Workspace

| Shortcut | Action |
|----------|--------|
| `V` | Validate |
| `A` | Auto-Bind |
| `Ctrl+B` | Export |
| `Ctrl+Shift+B` | Live Preview JUCE |

## Canvas (right-click context menu)

- Import Image
- Zoom to Fit / Zoom 100%
- Toggle Grid / Rulers
- Auto-Detect All Components
- Quick tool switching (V, C, R, S, W)

## Asset Library (right-click on asset)

- Select
- Edit in Foundry
- Export Asset
- Delete
