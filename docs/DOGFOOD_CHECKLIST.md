# צ'קליסט אימות חי — הזרימה המגוזמת (Extract → Export)

> עודכן 2026-07-05 אחרי הגיזום הגדול (Product Reset, פרוסה 1).
> **החזון:** תמונה נכנסת → נכסים חתוכים + רקע נקי + `layout.json` יוצאים לקלוד.
> זהו צ'קליסט אינטראקטיבי — צריך Electron רץ (`npm run dev` + `npm run electron`)
> ואת ה-sidecar של פייתון רץ (`cd python && python server.py`).

## לפני הכל
- [ ] ה-sidecar של פייתון עולה: `cd python && .venv/Scripts/python server.py` (או `python server.py`)
- [ ] מפתח Gemini מוגדר (⚙ Settings → מוח הזיהוי). בלי מפתח, הזיהוי נופל ל-CV בלבד.
- [ ] תמונת פאנל אמיתית מוכנה (mockup של סינת'/פלאגין).

## 1. ייבוא + זיהוי (שלב ① חילוץ)
1. הרץ את האפליקציה: `npm run dev` ואז `npm run electron`.
2. ודא שיש **סביבת עבודה אחת בלבד** בראש המסך ("① DETECT & CUT"); אין תפריט "Pro", אין Foundry/Animate/Design/Export/Market.
3. גרור תמונת פאנל לקנבס (או כפתור **Import Image**).
4. לחץ על הכפתור הראשי **✨ Detect Controls** → ה-analyzer נפתח (Gemini + SAM2 + OCR).
5. ודא: מופיעה שכבת-על עם הבקרים שזוהו + פאנל צד עם ספירת בקרים/סקשנים.
6. ודא שיישור פרספקטיבה רץ אוטומטית (אם התמונה מוטה) — מבלי שתעשה כלום.

## 2. ביקורת ותיקון
7. עבור על תור הביקורת: **Enter**=אשר · **X**=מחק · **1-6**=שנה סוג.
8. בחר בקר → פתח **Edit Mask** → צייר עם המברשת/מחק → **Ctrl+Z** מבטל.
9. נסה **Re-cut (K)** ו-**Lasso (L)** על בקר בעייתי; ודא שהחיתוך מתעדכן.
10. פאנל **✂️ Refine** (טווח/החלקה/נוצה) → כפתור SAM re-cut.

## 3. גזירה חופשית + הרכבה (שלב ② סידור — אופציונלי)
11. **Import & Cut Parts** → ייבא תמונה שנייה → לאסו/מלבן → "Cut to Tray"; ודא שהחלק מופיע במגש שקוף ונקי (בלי הילה).
12. **Compose Parts on Panel** → הנח חלק על הפאנל → הזז/סובב/שנה-גודל/סדר-Z.
13. פאנל Recolor (אם אלמנט נבחר): גוון/רוויה/בהירות/טינט → תצוגה חיה.

## 4. ייצוא (שלב ③)
14. **Export for Frontend / Claude** → נוצר `synthskin-handoff.zip`.
15. פתח את ה-zip וודא שיש בו: `layout.json`, `Panel.tsx`, `assets/<id>.png`,
    `background/background_filled.png` + `background_punched.png`, `preview.png`,
    `README_FOR_CLAUDE.md`.
16. ודא ש-`preview.png` נראה כמו הפאנל, ושהנכסים שקופים ונקיים מהילה (זום 400%).

## 5. שמירה/פתיחה
17. **Ctrl+S** → שמור `.synthskin`; **Ctrl+O** → פתח מחדש; ודא שהנכסים חזרו.

## 6. מבחן קלוד (המבחן העליון — שלב 3 בתוכנית)
18. פתח סשן קלוד נקי, מסור **רק** את `synthskin-handoff.zip`, ובקש לבנות UI ב-React.
19. כל שאלת הבהרה שקלוד שואל = חור ב-README או ב-layout.json → נרשם לתיקון.
