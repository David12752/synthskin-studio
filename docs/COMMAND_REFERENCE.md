# Command Reference

> All commands are accessible via the Command Palette (`Ctrl+K`). Commands with empty shortcuts are palette-only.

## File

| Command | Shortcut | Description |
|---------|----------|-------------|
| New Project | `Ctrl+N` | Create a new empty project |
| Open Project | `Ctrl+O` | Open an existing project file |
| Save Project | `Ctrl+S` | Save the current project |
| Save Project As | `Ctrl+Shift+S` | Save to a new location |

## Workspace

| Command | Shortcut | Description |
|---------|----------|-------------|
| Switch to Extract | `Ctrl+1` | Open the Extract workspace |
| Switch to Foundry | `Ctrl+2` | Open the Foundry workspace |
| Switch to Design | `Ctrl+3` | Open the Design workspace |
| Switch to Animate | `Ctrl+4` | Open the Animate workspace |
| Switch to Export | `Ctrl+5` | Open the Export workspace |

## View

| Command | Shortcut | Description |
|---------|----------|-------------|
| Toggle Fullscreen Canvas | `F` | Hide all panels, show canvas only |
| Toggle Distraction-Free Mode | `Shift+F` | Hide title bar, toolbars, status bar |
| Toggle Left Panel | — | Show/hide the left side panel |
| Toggle Right Panel | — | Show/hide the right side panel |
| Toggle Bottom Panel | — | Show/hide the bottom panel |

## Edit / History

| Command | Shortcut | Description |
|---------|----------|-------------|
| Undo | `Ctrl+Z` | Undo the last operation |
| Redo | `Ctrl+Shift+Z` | Redo the last undone operation |

## Extract Tools

*Only active in the Extract workspace.*

| Command | Shortcut | Description |
|---------|----------|-------------|
| Select Tool | `V` | Click to select assets on the canvas |
| Circle Extract Tool | `C` | Click center, drag to set radius |
| Rect Extract Tool | `R` | Click and drag a rectangle |
| Smart Select Tool | `S` | One-click auto-extract (multi-strategy) |
| Magic Wand Tool | `W` | Adjustable parameters: tolerance, feather, edge sensitivity |
| Hand / Pan Tool | `H` | Drag to pan the canvas |
| Zoom Tool | `Z` | Click to zoom in, Alt+click to zoom out |
| Auto-Detect All Components | — | Opens batch detection modal |
| Zoom to Fit | `Ctrl+0` | Fit the image to the viewport |

| Command | Shortcut | Description |
|---------|----------|-------------|

## Context Menus

Right-click on any of these areas for context-specific actions:

- **Canvas**: Import, zoom controls, grid toggle, tool switching, auto-detect
- **Asset Library card**: Select, edit in foundry, export, delete
- **Inspector panel**: Export, open studio, copy bounds, delete
- **Workspace tabs**: Quick workspace switching, fullscreen, distraction-free
